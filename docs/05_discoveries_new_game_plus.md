# フェーズ1 — 共有したくなる発見／周回仕様（提案 v0.1）

## 「そんなのあったの？」の設計原則
- 驚きの種類は **場所／時期／編成／行動／選択／周回／視点のずれ** を掛け合わせる。
- 隠し要素は、現地に小さな予兆、別人物から断片的な噂、時期を跨いだ変化、という最低2本の手掛かりを置く。
- 「何もしていない」のも選択になるが、重大な見逃しには兆候を示す。全要素の回収を強要しない。
- ランダムだけで決まる加入や終幕は作らない。少数の希少演出は確率でもよいが本質的な発見は条件再現可能に。
- 日誌は見つけた情報のみ記録し、未発見の一覧や収集率を初回は隠す。
- 発見IDごとにトリガー・手掛かり・報酬・取り逃し救済・時期差分・ネタバレ分類を用意。

### 発見の優先度
- フェーズ3採用：#01井戸、#04洞窟の壁、#17森の歌の簡易版、#26弱いスライム、#32不戦の守護者のうち2〜3件。
- 世界の核心情報に関わる隠し要素は、必須ルート以外からも取得可能にする。
- SNSなどにネタバレを共有できるが、ゲームUIで「発見カード」を作る場合は本文ではなく抽象的な一句と場所シルエットのみ出す（ネタバレ配慮）。

## 周回と引き継ぎの仕様
初回は通常の新規開始、ED到達後「新たな旅」を選択可能。ストーリー上は同じ世界の再演とは断言せず、記憶の違和感だけが残る。

| 状態 | 次周回へ | 理由 |
|---|---|---|
| アチーブメント（獲得済み） | **引継** | 探索と周回の証拠 |
| エンディング解放履歴 | **引継** | 周回限定分岐に利用 |
| 指定された継承アイテム | **引継** | 限定的な差分を生む |
| 主人公レベル・ステータス | リセット | 戦闘バランス維持 |
| ジョブ習熟・常時ボーナス | リセット | 先行周回の強さ固定を防ぐ |
| 仲間・好感度・編成 | リセット | 加入イベントを再体験 |
| 通常アイテム・装備・金銭 | リセット | 経済と選択の再構築 |
| 世界時計・世界時期・イベントフラグ | リセット | 時期限定体験が復活 |
| 地図踏破・噂ログ | 原則リセット | 探索の楽しさを保つ |
| オプション／操作設定 | 引継 | 利便性 |

### 継承アイテムの制約（仮）
- 特別枠を最大2枠。強武器や大量の金銭は対象外。
- アイテムには `carryover_allowed` と `carryover_cost` を持たせる。発見に関する「古い鍵」「割れた小舟の模型」など、低性能だが別の手掛かりに繋がる物を優先。
- 選択UIに「次の冒険には何を持ち込む？」を提示。未選択なら何も引き継がない。
- NG+専用条件は `achievement_unlocked`, `ending_seen`, `loop_count_gte`, `carryover_has` 等の宣言的述語で表現。ユーザーの「実績は覚えている」という世界観と一致。
- スロットは複数。元周回の最終セーブを上書きせず、別周回IDへ移行する。
- セーブ形式に `schema_version`, `content_version`, `run_id`, `loop_count` を含め、後方互換のマイグレーションを用意。

## 進行・実績フラグの責務
- `run_flags`: 周回内の決定。世界期、加入、クエスト、エリア変化。
- `meta_flags`: アカウント内（ローカル保存）の実績・ED履歴・継承可能アイテム。
- `storyline_state`: ラインの段階、最終選択、回収済み証拠。
- `discovery_log`: 見つけた発見IDのみ。別の周回の記録はメタ実績があるときだけ「既視感」として演出。
- コンテンツIDの変更は原則禁止。削除要素は移行表を用意し、失われたアイテムは安全な代替に変換。

## フェーズ3の小さい完成形
- 小フィールド＋洞窟、主人公＋3人の候補（うち1人時期1限定）。
- 世界期が変わることで**同じNPCの会話／敵配置／一部通行**が変わる。
- 物語ラインは「橋の向こう」を短縮して採用。二人加入済み、うち一人同行、時期2以降で進行。
- ED_DARKLORD と ED_BRIDGE に実際に到達でき、ED後に実績を保存して次周回へ。
- 8方向アニメ・多層マップ・大量キャラはまだ実装しない。
- 画像アセットは既存の画像生成PNGを再利用できるが、Godot向けの切り出し・命名規約を先に固定。

## 次に決める論点
1. 周回専用EDに必要な実績数と、演出上のネタバレの強さ。
2. 継承アイテムを2枠に制限するか。
3. 発見の共有UI（カード／スクリーンショット）を実装するか。
4. 意地悪な時期限定要素の上限（プレイ1周あたり取り逃し許容量）。
