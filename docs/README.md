## 方針と保留
- **20人・複数ストーリーラインに耐える拡張性**を最優先。条件・イベント・仲間・エンディングはフェーズ2でJSONに外出し。
- 原作のFF5/FF6は雰囲気の参照。既存の画像や音楽、キャラデザインは流用せずオリジナル素材を使用する。
- ユーザーとの従来の合意により、ゲーム世界の画像素材は**画像生成で作成**。コードで地形やキャラのドット絵を自動描画しない。仮UI図形は可。
- **確定していない項目は提案扱い**：世界時計の閾値、仲間候補の詳細、3–5時間の初回目標、ED数、ジョブリスト、戦闘の速度順制など。
- フェーズ2は本ドキュメントのレビュー後に着手。

## 最初に決定したい5点
1. 戦闘枠：主人公固定＋仲間3で良いか。
2. 世界時計：日数型（地域移動・宿泊等で消費）か。
3. 時期閾値：20日/45日/60日（暫定）で試すか。
4. 初回プレイ時間：3〜5時間想定で良いか。
5. Godot 4版を既存ブラウザ版から分離し、Web向け実機テストを早期に実施するか。

次フェーズでは JSONスキーマ、宣言的条件評価器、保存・周回データ、仲間3人＋ライン1つ＋ED2種類のサンプルを作る。
## ユーザーによる確定事項（2026-11-11）
- 主人公＋仲間3人の4人パーティ
- 宿泊・地域移動・重要イベントで世界日数が進行
- 初回クリアの目標は3〜5時間
- Godot 4版は既存ブラウザ版と分離して制作
**これらはフェーズ2の基準仕様。** 日数閾値等の細部は暫定。
