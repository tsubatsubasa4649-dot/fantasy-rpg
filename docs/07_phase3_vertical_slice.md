# フェーズ3 — Godot 4 縦切りプロトタイプ

**実装状態：Godot 4.3でフェーズ2・3・UIスモークテスト全件成功／Web書き出しとGitHubへの公開ファイル配置も成功。iPhone Safari実機プレイは未確認。**

既存のルート直下 `index.html` は従来のブラウザ試作品として維持。
本命のGodot 4版は `godot/` 以下の別プロジェクト。

## 実装したループ
1. `field`（始まりの村と草原）を移動。以前生成したPNG8種類を再利用する。
2. リッキー（夜回り）、メリル（前兆期限定／森の手掛かり）、ゴロー（崩壊期以降／避難民救出）をJSONのイベントで加入。
3. 主人公＋最大3人の4人パーティを編成。
4. 宿屋の1日、地域間移動の2日、遠征の10日で世界が前兆期→崩壊期→終末期へ進行。
5. NPC台詞・出現人物・実際の壁配置（`phase_rows`）が時期によって変化。
6. `cave`（風鳴りの洞窟）で通常スライムと、終末期に出現する「魔王の影」とサイドビューのコマンド戦闘。
7. 魔王の影の勝利で **ED_DARKLORD**。またはリッキー＋メリルが加入し、メリルが現編成にいる状態で橋の謎を解いて **ED_BRIDGE**。
8. セーブ、ロード、周回（実績引継ぎ、仲間・時間リセット）を共有のゲームセッションで管理。

### 触り方
- 起動シーン：`res://scenes/vertical_slice.tscn`
- 方向ボタンまたはキーボード矢印／WASDで移動。「調べる」や近くのNPC用ボタンを押す。
- 仲間は加入後に「編成を整える」で自動編成。戦闘は1人ずつ **攻撃／技／防御** を選ぶ。
- 橋の物語を見るには時期1のうちに**メリルを加入**させておく。時期2に到達後、リッキーとメリル加入済み、メリルを戦闘編成に入れ、壊れた橋で調査→解決→EDを選ぶ。
- 魔王の影は時期3になるまで戦えない。洞窟のスライムと戦ってからでもよい。
- フェーズ3はデザイン検証用で難度・日数は仮。

## ファイル
- `data/maps.json`：フィールド／洞窟2領域・各時期の地形・NPC・会話・インタラクトをデータ管理
- `data/battles.json`：敵と味方の戦闘パラメータ・勝利イベント
- `data/events.json`：時間経過・仲間・橋・魔王のイベント
- `scripts/vertical_slice.gd`：入力、地形と立ち絵の表示、状態に応じたUI
- `scripts/battle_engine.gd`：4人コマンド入力、与ダメージ、敵の反撃、勝敗
- `assets/*.b64`：チャットで生成したPNGのBase64データ。起動時にデコードしてImageTextureとして使う。画像をコード生成しない。
- `tests/test_phase3.gd`：世界時期、仲間、4人編成、戦闘、2種EDの自動テスト
- `export_presets.cfg`：Godot Web向け。JSONとB64同梱、スレッド無効
- `../.github/workflows/godot-web.yml`：Godot実行テスト・WebビルドをGitHub Actionsで実行し `godot-play/` に出力
