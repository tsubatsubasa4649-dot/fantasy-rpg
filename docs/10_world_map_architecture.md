# WORLD-16: ワールドマップ分離（Godot 4）

## 実装範囲
- 既存の `field`（ウィンドル）と `cave`（風鳴りの洞窟）は独立したローカルマップとして維持
- 新たに `world_map`（40×24セル）を `godot/data/maps.json` に追加。矩形全体を陸地にするのではなく、海に囲まれた不規則な海岸線で大陸形状を表す
- 地形記号: `~` 海（通行不可）、`#` 山岳（通行不可）、`f` 森、`p` 街道、`.` 平地
- 世界地図には始まりの村、風鳴りの洞窟、古い石橋、ささやきの森、旧文明の塔、南の交易都市を配置
- 東西・南北に分岐する街道で探索順序を固定しない
- 崩壊期・終末期の地形差分を `phase_rows` に保持
- UIは10×7セルだけを描画。主人公位置を基準に `_camera_origin()` が表示対象を切り替え、スマホ画面に40×24セルを無理に縮小しない
- 村出口→世界地図→洞窟→世界地図など、往復ごとのスポーン座標は各ポイントの `spawn` で設定

## 既存機能との互換性
既存の仲間加入、戦闘、セーブ・ロード、時間経過の実装は維持。新規拠点のイベントはマップポイントと宣言的な `actions` で追加し、マップの存在参照はレジストリ検証に任せる。

## 未実装・留意点
- **新しい専用の海・山・森タイル画像はまだ未作成**。現段階では既存の生成画像を地形タイプごとに色調変更して表示する。仮美術であり完成マップの見た目ではない
- ワールドカメラは移動完了ごとに隣接表示へ追従する方式。描画位置の連続的なパン／ズーム機能は今後の課題
- 塔・森・南の交易都市は探索・噂・外観の段階であり、内部専用マップや長編イベントは未実装
- 海岸線と山脈はデータで形状を定義。世界の探索規模拡大時はチャンク化とズーム可能なマップ画面を検討
