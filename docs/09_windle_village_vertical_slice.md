# 始まりの村ウィンドル — VILLAGE-15

この文書は Godot 4 の縦切りプロトタイプで実装した村の設計と制限を記録する。

## 実装した村
- 10×7セルの小規模マップ。中央寄りの村の入口（4,5）から開始する。
- 道を示す `p` シンボルが入口、中央広場、東の峠を結ぶ。草原の既存生成画像に色調の変化を与えて道を区別する暫定表現。**独立した土・石畳の完成アートではない**。
- 既存の生成画像を使う家2軒（西の家、東の宿屋）。家の屋根タイル（H）は通り抜け不可。
- リッキー（西）、メリル（北側）、ゴロー（時期2〜）、宿屋（東）、洞窟入口（北東）、壊れた橋（時期2〜）。
- 村の案内板（3,5）、井戸（5,3）、峠の道標（7,2）を調査できる。案内板・井戸には一度だけ取得するフラグと、発見後の会話選択肢がある。
- NPCまたは調査対象に向いたとき、その対象の行動を優先する。重なった近接対象を選び間違いにくい。
- 世界が崩壊期・終末期へ進むと通路が部分的に崩れる。

## 素材と今後の制作
既存の生成ドット絵を再利用。UI・地形のグリッド描画や色調補正は実装処理だが、**新たな木・柵・看板・井戸・道の専用ピクセルアートはまだ用意していない**。現状はイベント位置とシーン構成の先行実装で、村の完成美術ではない。

次は ChatGPT 生成の独立したタイルセット（石畳・木・花壇・井戸・看板・柵）を制作し、既存のJSONシンボルと対応させる。家も現在1種類の画像を2軒で使用しているため、宿屋と民家で違うグラフィックが必要。

## 確認項目
1. iPhoneで `VILLAGE-15` が表示されること。
2. 開始位置が左端ではなく村入口寄りであること。
3. 色の違う道で東の洞窟まで歩けること。
4. 家の屋根を通り抜けられないこと。
5. 案内板・井戸の発見がフラグとして保持されること。
6. 既存の仲間加入・洞窟移動・EDが壊れていないこと。
