# 画像素材の置き場所

このゲームは画像をコードで描画・代用せず、PNGを読み込む方式です。画像がない状態では画面は暗いままで、ステータスと操作ボタンのみ表示されます。

このフォルダに次のPNGを配置してください。

- ground.png — 地面（32×32）
- wall.png — 岩・壁（32×32）
- house.png — 宿屋（32×32）
- cave-entrance.png — 洞窟入口（32×32）
- elder.png — 村の長老（32×32）
- hero.png — 主人公（32×32）
- slime.png — スライム（32×32）
- guardian.png — 洞窟の守護者（32×32）

現段階は開発用の最小構成です。後日画像を生成し、キャラアニメーションとマップ素材を拡張します。
