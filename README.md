# 終わりの地図 — 2D RPG

Godot 4.3 / Web向けの、16pxドット絵と見下ろし探索・サイドビュー戦闘によるRPGです。

**プレイ:** https://tsubatsubasa4649-dot.github.io/fantasy-rpg/godot-play/

## 最初の村 ウィンドル（VILLAGE-24）

- CAMERA-22の8×6マス表示・整数倍拡大と滑らかな追従カメラは維持
- 村を22×16マスに拡張。石畳の広場、花畑、農地、木立、北門などを配置
- 新規作成した画像素材`godot/assets/village_atlas.b64`を直接16×16で切り出して描画。コードによる地形画像生成はしない
- リッキー、メリル、ゴローに加え、長老、薬師、子ども、商人、農夫、門番などの会話を実装
- 宿屋で1日休むと戦闘で減ったHPが全回復。HPは戦闘間・セーブ時に保持
- 村の案内板、井戸、祈りの石、花壇、宿屋の備蓄などを調査して進められる
- 最初の旅の目標：リッキーの夜回りを手伝う → 仲間を増やす → 北東の門から世界地図へ

スマホでは十字キーで移動、**話す・調べる**で近くのNPCや施設にアクセスします。メニューから目標確認、編成、セーブ、ロードが可能です。

## テスト

GitHub ActionsはGodotのデータ・戦闘・UIテスト、村の全地点への到達性テスト、Web書き出しを自動実行します。
Godotをローカルに導入済みなら`godot --headless --path godot --script res://tests/test_village.gd`も利用できます。

**現段階の制限:** 村の地形素材は刷新しましたが、建物/NPCの一部は既存スプライトを再利用しています。独立した室内マップや店の売買システムはまだありません。
